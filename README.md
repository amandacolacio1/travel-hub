# Travel Hub

Aplicação web com Next.js, React e Zustand.

## Requisitos

- Node.js 20.9+ (recomendado: 22)

## Começando

```bash
nvm use
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Zustand (`src/stores`)
