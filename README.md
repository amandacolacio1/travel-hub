# ✈️ Travel Hub

> Um dashboard inteligente para comparar destinos e ajudar usuários a decidir sua próxima viagem com apoio de Inteligência Artificial.

## 📖 Sobre

O **Travel Hub** é uma aplicação web que centraliza informações importantes para o planejamento de viagens, permitindo comparar destinos com base em fatores como orçamento, época da viagem, clima, perfil do viajante e atrações.

A proposta é utilizar IA para transformar esses dados em recomendações personalizadas, tornando a decisão mais simples e contextualizada.

## 🎯 Objetivo

Este projeto está sendo desenvolvido com foco em estudo, explorando conceitos modernos de desenvolvimento Full Stack e IA.

Durante o desenvolvimento serão aprofundados temas como:

- Arquitetura de aplicações React
- Performance front end
- Consumo e integração de múltiplas APIs
- Gerenciamento de estado e Server State
- Integração com modelos de IA
- Engenharia de prompts
- UX para produtos orientados à tomada de decisão

## 🚀 Funcionalidades planejadas

- Cadastro com 3 etapas para ter preferências do usuário
- Dashboard com ranking inteligente de destinos
- Comparação entre destinos
- Informações sobre clima, câmbio, custos e melhor época para viajar
- Recomendações e justificativas geradas por IA
- Experiências personalizadas de acordo com o perfil do usuário

## 🛠️ Stack

- React + TypeScript
- Next.js
- TanStack Query
- Zustand
- Tailwind CSS
- Node.js 

# 🚀 Executando o projeto

#### Requisitos: Node.js 20.9+ (recomendado: 22)

```bash
nvm use
npm install
npm run dev
```
